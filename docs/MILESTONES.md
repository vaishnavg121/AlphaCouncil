| M7 | Position monitoring/exit management: state, thesis validity, exits, kill switch. |
| M8 | Journal/trading memory: decisions, evaluation, lessons, similarity retrieval. |
| M9 | Backtesting: simulation, benchmarks, Sharpe, drawdown, win rate, slippage. |

| M11 | Hardening/deployment/demo: tests, reliability, polish, deployment, submission. |
